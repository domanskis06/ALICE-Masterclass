Event Exploration short tutorial

In heavy ion collisions a hot, dense medium can form. High momentum particles lose energy in that medium (jet quenching). The nuclear modification factor RAA compares particle production in PbPb to proton proton collisions.

This first exercise builds intuition on single events: navigate collisions, read Event Characteristics histograms, and learn to keep only charged primary tracks, the same objects real ALICE analyses count for RAA.
